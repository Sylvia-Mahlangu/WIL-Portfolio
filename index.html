About DENIS

DENIS is a South African company that has specialised in managing dental benefits for medical schemes since 1996. It uses technology to support dental benefit management. In simple words, DENIS helps medical schemes manage the dental benefits available to their members, including claims and treatment authorisations.

Dental Claims

Processing information about dental treatments submitted for payment.

Dental Benefits

Helping administer the benefits available under different medical schemes.

Treatment Authorisations

Assessing certain treatments before they are performed, according to the scheme's rules.

Provider Networks

Working with dentists and dental practices.

Technology Systems

Supporting the digital systems used to manage these services.

The IT Department

The IT department makes sure the company's computers, software, networks and information systems work properly so employees can do their jobs.

Technical Support

Helping staff when computers, printers, email or software fail.

Networks & Infrastructure

Keeping the network and internet connections running so staff can reach the systems they need.

Cybersecurity & Data Protection

Protecting systems from unauthorised access, malware and data loss, especially for confidential member information.

Systems, Databases & Backups

Supporting business applications and making sure information can be recovered.

My Role as an IT Intern

I assist the IT team with network support and with system issues reported by call-centre agents, learning how IT works in a real business environment under supervision.

Network support

Helping with network and connectivity issues and learning how computers connect to the company network.

Call-centre system support

Assisting call-centre agents when they have problems with the systems they use, so they can keep helping callers.

User Stories & Tasks

What the people I support need from IT, and the tasks that address those needs.

Written as: As a [user], I want [goal], so that [benefit]. Edit these so they match the real issues you handle.

US-01 · High

As a call-centre agent, I want to report a system problem and have it logged, so that it gets tracked until it is fixed.

  • The issue is recorded with date, description and agent's department
  • The agent knows the issue has been received
Tasks: log the request · confirm with the agent · hand over or escalate if needed
US-02 · High

As a call-centre agent, I want my system problem resolved quickly, so that I can keep helping callers.

  • Common problems are checked and fixed or escalated
  • The agent confirms the system works again
Tasks: diagnose the problem · apply an approved fix · confirm with the agent
US-03 · Medium

As an IT team member, I want network issues recorded with their symptoms and fix, so that the team can reuse the solution.

  • Each network issue has a recorded cause and fix
Tasks: note symptoms · record the fix · update the logbook
US-04 · Medium

As a supervisor, I want to see which problems keep recurring, so that we can prevent them.

  • Recurring issues are identified from the logbook
Tasks: review the logbook · list repeat issues · report to the supervisor
US-05 · Low

As an intern, I want clear procedures to follow, so that I help safely and know when to ask.

  • I follow approved steps and ask before changing settings
Tasks: read procedures · confirm unclear steps with the supervisor
